MyGround compared

With Umbrel, CasaOS, Cosmos, YunoHost and Runtipi. Checked on October 27, 2026.

These are the platforms people weigh when they want to run apps like Immich, Jellyfin and Nextcloud on a machine at home. All six install apps in Docker and manage them from a web dashboard. This page shows where they differ, using each project's own site, docs and GitHub repository. Projects change quickly, so the sources are at the end, and if something here is out of date, open an issue and it will be fixed.

MyGround is the youngest and smallest of the six, and the table says plainly where it's behind.

Notes: MyGround installs Docker if it isn't there. Umbrel's hourly backups are encrypted and go to a USB drive, a NAS or another Umbrel, and Rewind restores single files. Cosmos backs up with restic, incrementally and encrypted, to remote storage; YunoHost makes archives from its web admin or the command line; Runtipi backs up an app's data, for example before an update. Umbrel's apps such as Ollama and Jellyfin use the GPU automatically, while MyGround switches it on per app (Immich, Jellyfin). MyGround's REST API comes with an OpenAPI spec and API keys.

Where MyGround is ahead

  • Off-site backups out of the box. Every app gets restic backups on its own schedule, to S3, Backblaze B2, Wasabi or a disk, with database dumps, snapshot browsing and one-click restore. Interrupted backups resume on restart.
  • Remote access without opening ports. Each app can get its own Tailscale node with automatic HTTPS, the server can be your exit node with Pi-hole blocking ads on the go, and any app can go public through a Cloudflare Tunnel.
  • Runs on what you have. It's one binary on the Linux or macOS machine you already use, not an operating system that takes over the disk.
  • Scriptable. Everything the dashboard does is in the CLI and the REST API, so a script or an AI agent can install apps, run backups and check health.
  • MIT licensed. No noncommercial or anti-resale clauses.

Where MyGround is behind

  • Far fewer apps. MyGround has 31 curated apps; Umbrel, Runtipi and YunoHost each have hundreds.
  • It's young. The first release came out in March 2026, it has ten GitHub stars, and one developer works on it.
  • No hardware to buy. If you want a box that arrives ready to plug in, Umbrel sells one.
  • No email hosting. YunoHost can run your mail server; MyGround doesn't try to.

Which one fits

  • You want a polished appliance with a big app store, for personal use: Umbrel. Read its noncommercial license first if it's for work.
  • You want the largest catalog and your own email server: YunoHost.
  • You want a simple dashboard on a Linux box you already run: CasaOS or Runtipi.
  • You want a security layer in front of all your containers: Cosmos.
  • You want the popular apps with off-site backups, per-app Tailscale HTTPS, GPU switches and an API your scripts and agents can drive, under the MIT license: MyGround. curl -fsSL https://myground.online/install.sh | sh
